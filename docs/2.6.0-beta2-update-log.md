# XueLiang Cloud AI Generation Beta 2 Release Notes

## Highlights

Beta 2 refined the first AI generation release by improving drawing-page usability, worker visibility, prompt generation, asset selection, character presets, and dual-character workflows.

## Frontend Changes

- Improved the AI drawing page layout and active job tracking.
- Added clearer service status and queue visibility.
- Improved prompt translation and prompt reuse flows.
- Upgraded LoRA, checkpoint, character, and prompt preset selection.
- Added early dual-character controls and region guidance.
- Added current-job polling and clearer failure display.

## Backend Changes

- Expanded AI generation schema after the original V12 migration.
- Added prompt translation jobs.
- Added dual-character and mask fields.
- Added worker stage/detail tracing.
- Added NSFW generation flags and visibility-level fields.

## Worker Changes

- Improved health checks for ComfyUI, Ollama, cloud connectivity, model directories, and default checkpoint.
- Added capability reporting for more local asset metadata.
- Added dual-character prompt/region strategies.
