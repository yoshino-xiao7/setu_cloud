# 雪凉云 2.6.0 更新日志

## 版本重点

2.6.0 引入了独立 AI 绘画服务，覆盖前端控制台、Spring Boot 后端以及 Windows 本地 worker。

## 前端

- 新增用户侧 AI 绘图、AI 历史和 AI 广场页面。
- 新增管理侧 AI 生成记录和审核队列页面。
- 支持 checkpoint、LoRA、角色、尺寸、steps、CFG 和 seed 等参数。
- 支持用户把完成后的私有图片提交审核，审核通过后进入公共 AI 广场。
- 前端只使用后端返回的签名预览地址，不直接读取 OSS key。

## 后端

- 新增 AI 任务、审核、worker 和 worker 能力缓存表。
- 新增 `/ai/**` 用户会话接口。
- 新增 `/ai-api/**` API Key 接口。
- 新增 `/ai-worker/**` worker 轮询接口。
- 新增 `/admin/ai/**` 管理员接口。
- 普通用户扣积分，管理员记录 0 积分调用。
- worker 回传图片字节后，由云端写入私有 OSS。

## 本地 Worker

- `setu_ai_wife` 新增 cloud worker 模式。
- 支持上报模型和 LoRA 能力。
- 支持本地 ComfyUI 出图并回写云端任务。
- 云服务器不需要访问本机内网地址。

## 当前后续状态

当前代码已经超过最初 2.6.0 版本。最新说明请优先阅读：

- `setu_cloud/docs/ai-generation-pages.zh.md`
- `setu_api_full/docs/ai-generation-service.zh.md`
- `setu_ai_wife/docs/CLOUD_WORKER.zh.md`

这些文档覆盖当前的提示词翻译、局部重绘、删除申请、本地图片删除、私有 OSS 保留期、服务状态和 worker trace 等能力。
