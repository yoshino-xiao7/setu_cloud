# XueLiang Cloud 2.6.0 Release Notes

## Highlights

2.6.0 introduced the independent AI generation service across the frontend console, Spring Boot backend, and the Windows local worker.

## Frontend

- Added user pages for AI drawing, AI history, and AI Square.
- Added admin pages for AI generation records and review queues.
- Added checkpoint, LoRA, character, dimensions, steps, CFG, and seed controls.
- Added review submission so completed private images can enter the public AI Square after approval.
- Added signed preview URL usage; the frontend never reads raw OSS keys directly.

## Backend

- Added AI job, review, worker, and worker capability persistence.
- Added session APIs under `/ai/**`.
- Added API-key APIs under `/ai-api/**`.
- Added worker polling APIs under `/ai-worker/**`.
- Added admin APIs under `/admin/ai/**`.
- Added point charging for normal users and zero-cost accounting for admins.
- Added cloud-side private OSS writes from worker-completed image bytes.

## Local Worker

- Added cloud worker mode in `setu_ai_wife`.
- Added model and LoRA capability reporting.
- Added local ComfyUI generation with cloud job completion.
- Kept the cloud server independent from local machine inbound networking.

## Current Follow-up State

The latest codebase has advanced beyond the original 2.6.0 release. Current docs should be read together with:

- `setu_cloud/docs/ai-generation-pages.md`
- `setu_api_full/docs/ai-generation-service.md`
- `setu_ai_wife/docs/CLOUD_WORKER.md`

Those files document the current prompt translation, inpaint, delete request, local image deletion, retention, status, and worker trace features.
